# Project 04: 請求・入金管理SaaS「Lumina Books」(選択)

Luminaは予約システムを他のサロンにも「Lumina Reserve Cloud」としてSaaS提供し始めました。加入サロンへの月額課金は、請求書の発行も入金の確認もスプレッドシート手作業。件数が増えて破綻寸前です。経理チームのための請求・入金管理システムを作ります。

- 仕様リポジトリ: [curriculum-project-billing-saas](https://github.com/dik-ab/curriculum-project-billing-saas)
- 目安: 5〜6週(AI駆動前提)
- 必要なもの: ローカル環境のみ

## このプロジェクトで身につくこと

**お金を扱うコード**は、実務でもっとも間違えられないコードです。1円のズレが経理を止めます。

| テーマ | 具体的には |
| --- | --- |
| 金額計算 | 浮動小数点を使わない設計、消費税の端数処理(請求書単位・切り捨て)をテストで固定する |
| 冪等な採番 | INV-2026-0001形式の請求書番号を、同時発行でも重複させない |
| 状態機械 | draft → issued → paid / partially_paid / overdue → void。不正遷移を型とテストで禁止する |
| 入金消込 | 銀行CSVの取込、金額・名義での自動マッチング、部分入金、誤消込の解除 |
| 集計SQL | 月次売上、未収金エイジング(30/60/90日)、テナント別MRR |
| 帳票 | 請求書PDFの生成とメール送付 |

「請求・消込を作ったことがある」は経理・SaaS・EC系の実務で強く効く経験です。会計ドメインの入口として設計しています。

## 主な機能(Must)

- テナント(顧客)・プラン・契約の管理、admin/viewerロール
- 請求書作成(明細行、税計算、採番)、発行でPDF生成+メール送付
- 毎月1日の定期請求ドラフト一括生成(スケジューラ)と一括発行
- 入金の手動登録・銀行CSVインポート・自動マッチング・手動消込・部分入金
- 期限超過のoverdue自動化と督促メール
- 月次売上・未収金エイジングのレポート

## マイルストーン

| マイルストーン | 内容 | issue数 |
| --- | --- | --- |
| M1: 基盤とマスタ管理 | 認証、テナント、プラン・契約、監査ログ | 5 |
| M2: 請求書 | 明細と税計算、採番(同時実行テスト)、発行フロー、PDF | 5 |
| M3: 定期請求と入金 | 一括生成、CSV取込、自動マッチング、消込 | 6 |
| M4: レポートと運用 | 督促、月次レポート、CI、仕上げ | 4 |

M2の税計算と採番、M3の消込が山場です。`money-and-ledger` スキルに端数処理の正確な仕様、採番の実装パターン、消込データモデルの不変条件、金額テストの境界値表があります。
